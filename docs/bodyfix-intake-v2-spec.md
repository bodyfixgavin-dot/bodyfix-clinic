## 3. 品牌語言

BodyFix 筋膜整理，是以運動按摩為基礎，透過筋膜線判讀與張力分工整理，在低痛感、可呼吸、身體能接受的深度裡，讓肌肉與外層筋膜一起回到更穩定、有韌性、有彈性的狀態。

固定方法只有四步：**READ → RESET → RECONNECT → RETURN**。核心不是把人按得很痛或只做短暫放鬆，而是判讀身體如何承受、代償與分工，再在身體可以接受的深度中重新整理張力與使用方式。避免「越痛越有效」、硬壓痛點、喬骨、整骨、治療疾病、矯正骨骼、過度醫療化與療效保證。

## 4. 開場

**標題：** 預約前，先讓我認識你的身體

**文字：** 大約 2–3 分鐘。每個人的身體使用方式、訓練習慣與張力分工都不同。這份問卷會讓我在見面前先了解你的狀況，把現場時間留給真正重要的：READ → RESET → RECONNECT → RETURN。沒有標準答案，照你現在實際的感受填寫即可。BodyFix 為運動按摩、筋膜整理與動作訓練服務，不取代醫療診斷與治療。

## 5. 完整問卷

### A｜基本資料

1. **怎麼稱呼你？** 必填短文字；placeholder「暱稱就可以」。
2. **方便聯絡你的方式？** 必填單選：LINE、Instagram、Facebook / Messenger、電話、其他。
   - **Q2-1 聯絡內容**必填短文字；placeholder「讓我知道預約的是哪一位就好」。
3. **這次是？** 必填：第一次預約 BodyFix、之前來過、曾上過 Gavin 的教練課、曾做過筋膜整理也上過教練課。
4. **你怎麼知道 BodyFix 的？** 必填：Instagram、Twitter / X、Threads、Facebook、LINE 官方帳號、Google 搜尋、PRO360、朋友介紹、之前就是 Gavin 的客戶／學生、其他。

### B｜這次想做什麼？

5. **主要想了解哪一種服務？** 必填單選。身體整理列出 Body Reset、Pelvic Core Reset、指定筋膜線、多線整合、Pelvic Core VIP 的 canonical 名稱、時間與定位；Movement 列出 Movement Training 一對一與 Movement Training＋筋膜整理；另有「不知道該選哪個，希望 Gavin 看完狀況後建議」。
6. **最主要想改善什麼？** 必填複選：身體一直很緊很痠、某處反覆卡住、活動度受影響、運動動作不順、恢復慢、久坐／久站不舒服、肩頸背腰易累、髖骨盆不順、內側／髖前緊、完整全身整理、重新規律訓練、增加肌肉／力量、改善動作品質、無不適只想整理、不確定但覺得怪、其他。

### F｜安全確認

## 6. 完成頁、摘要與 LINE

正常標題「填好了 👍」，說明 Gavin 會先閱讀，現場仍會再 READ；人工確認時標題「資料已整理完成」並使用上述 review 文案。主要按鈕「複製問卷並開啟 LINE」，次要按鈕「重新檢查答案」。沿用 repository 正式 LINE 連結，不猜新 ID。

純文字摘要以 `【BodyFix Intake v2.0】` 開頭，依序含稱呼、聯絡、首次／回訪、來源、預計服務、目的、區域、狀況、感受、影響、持續時間、工作、運動頻率／種類、過去處理／結果、安全、需人工確認、深度、不希望區域；觸發時才輸出 `【Pelvic Core】`（方向、範圍、界線完成、18+）與 `【Movement】`（目標、經驗、不舒服動作、安排）；最後含期待、補充、填寫日期。空白選填省略，不大量輸出「無／未填」。

流程為 form → browser memory state → formatted summary → clipboard → LINE。剪貼簿失敗時保留 summary 並顯示可手動複製 textarea 與 LINE 連結。
